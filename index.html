Nhà cung cấp AI
Chọn dịch vụ AI
Chọn AI nào mày muốn dùng. Mặc định dùng Gemini vì miễn phí dễ lấy key.
Gemini API Key
Lấy miễn phí tại aistudio.google.com/apikey. Key lưu trên máy mày, không gửi đi đâu khác.
Model: gemini-2.5-flash (nhanh, miễn phí)
Claude API Key
Lấy tại console.anthropic.com. Cần nạp tiền để dùng.
Model: claude-sonnet-4
⚠ Lưu ý: Claude API không cho gọi trực tiếp từ trình duyệt do CORS. Cần dùng proxy hoặc chạy trong Claude.ai.
OpenAI API Key
Lấy tại platform.openai.com/api-keys. Cần nạp tiền để dùng.
Model: gpt-4o-mini (rẻ & nhanh)
Bảo mật
Xoá key đang lưu
Xoá toàn bộ API key khỏi trình duyệt. Sau khi xoá sẽ không gọi được AI nữa cho đến khi nhập lại.
Lưu ý về bảo mật: API key được lưu trong localStorage trình duyệt của mày. Không upload lên server. Tuy nhiên nếu dùng máy chung, người khác mở file này có thể thấy key. Nên dùng máy riêng hoặc xoá key sau khi xong.
